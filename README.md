# MMJ Wireless Link Quality Tester (CLI Edition)

シリアル通信（無線モデム等）の通信品質を評価するためのコマンドラインツールセットです。
GUIを使わない軽量・高信頼設計で、**パケットロス率**および**ビット誤り率（BER）**を正確に測定します。

## 特徴

* **対話型ポート選択:** 起動時に接続されているCOMポートを一覧表示し、番号入力だけで接続可能。
* **KISSプロトコル準拠:** FEND/FESCによるエスケープ処理を実装。
* **パケットロス検出:** 16bitシーケンスカウンタにより、パケットの欠落を検知。
* **ビット誤り検出:** PN9（疑似ランダム系列 $x^9 + x^5 + 1$）を使用し、データ化けを検出。
* **CSVログ保存:** 受信データをタイムスタンプ付きで全記録。

## 必要要件

* Python 3.8 以上
* ライブラリ: `pyserial`

```bash
pip install pyserial

```

## 📡 使い方 (Usage)

### 1. 受信機 (Receiver) の起動

まずは受信側を立ち上げて待ち受け状態にします。
引数なしで実行すると、**ポート選択モード**になります。

```bash
python kiss_receiver.py

```

**実行後の画面（例）:**
PCに接続されているシリアルポートが一覧表示されます。使用するポートの番号を入力してください。

```text
=== SERIAL PORT SELECTION ===
  [0] COM3 (USB Serial Port)
  [1] COM11 (Standard Serial)
=============================
Select Port Number (0-1) > 1

```

*(ここで `1` を押して Enter すると受信開始)*

> **Note:** 自動化などでポートを固定したい場合は、`--port COM11` のように引数で指定すれば選択画面をスキップできます。

### 2. 送信機 (Sender) の起動

別のターミナルで送信機を起動します。

```bash
python kiss_sender.py --port COM10

```

※ `COM10` の部分は送信機がつながっているポートに変えてください。

**詳細設定（オプション）:**
受信側と設定（ボーレートやサイズ）を合わせる必要があります。

```bash
python kiss_sender.py --port COM10 --baud 9600 --size 16 --interval 0.5

```

| オプション | デフォルト | 説明 |
| --- | --- | --- |
| `--baud` | 9600 | 通信速度 (bps) |
| `--size` | 16 | パケットサイズ (byte)。**送受で一致必須** |
| `--interval` | 0.5 | 送信間隔 (秒) |
| `--pn9-reset-each` | Off | パケット毎に乱数をリセットするか (送受で一致必須) |

## ログファイルと解析

受信機を停止（Ctrl+C）すると、実行フォルダにCSVファイルが生成されます。
ファイル名形式: `YYYYMMDD_HHMMSS_rx_log.csv`

**CSVの中身:**
Excel等で開いて分析可能です。

| カラム | 内容 | 判定基準 |
| --- | --- | --- |
| **Status** | 判定結果 | `OK` なら正常。`DATA_CORRUPT` はデータ化けあり。 |
| **RecvCounter** | 受信番号 | 連番になっているか確認できます。 |
| **ExpectedCounter** | 期待番号 | ここが飛んでいると「パケットロス」です。 |
| **BitErrors** | エラー数 | `0` なら正常。数字があればそのビット数だけ化けています。 |

## よくある質問

**Q. ポート一覧に何も出ない**
A. USBケーブルが正しく接続されているか確認してください。ドライバが当たっていない可能性があります。

**Q. 全て `DATA_CORRUPT` になる**
A. 送信側の `--size` と受信側の設定が合っているか確認してください。また、`--pn9-reset-each` オプションの有無が一致しているかも重要です。

**Q. 文字化けして読めない**
A. `--baud` (ボーレート) が無線機の設定と一致しているか確認してください。
