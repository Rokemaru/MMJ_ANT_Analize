# MMJ Wireless Link Quality Tester (Complete Manual)

無線モデムやシリアル通信機器の品質評価を行うためのツールセットです。
KISSプロトコルとPN9（疑似ランダムパターン）を用いて、**パケット到達率**および**ビット誤り率（BER）**を正確に測定します。

**★ 最新機能 (v8.0)**
* **Auto Sync:** 受信開始タイミングがズレても、自動計算で追いつき正常受信します。
* **Full Trace:** 受信したデータ(`RxHex`)だけでなく、送信されたはずの正解データ(`TxHex`)もログに残します。

## 📂 ファイル構成

| ファイル名 | 種類 | 役割 |
| :--- | :--- | :--- |
| **kiss_sender.py** | CUI | **送信機**: テストデータを生成して送り続けます。 |
| **ANT_Analyzer.py** | CUI | **受信機(軽量版)**: コマンド画面で動作する軽量レシーバー。 |
| **ANT_Analyzer_GUI.py** | GUI | **受信機(高機能版)**: 某ポストアポカリプスゲーム風GUI。自動同期・詳細ログ保存機能付き。 |

## ⚙️ 共通設定・パラメータの意味

**※ 送信側と受信側で設定がズレていると、通信は成功しません。必ず一致させてください。**

| パラメータ名 | 意味 | 推奨値・注意点 |
| :--- | :--- | :--- |
| **PORT** | **通信ポート** | PCに接続した機器のCOM番号（COM3, COM10など）。 |
| **BAUD** | **通信速度** | `9600` など。無線機の設定と完全に一致させる必要があります。 |
| **SIZE** | **パケットサイズ** | `16` ～ `64` 推奨。送受信でバイト数を合わせる必要があります。 |
| **INTERVAL** | **送信間隔** | `0.5` (秒) 推奨。送信ペースです。 |
| **PN9-RST** | **乱数リセット** | **ON推奨**。パケット毎に同じ乱数パターンを使います（カウンタは進みます）。設定ミスや同期ズレに強く、確実に比較できます。 |

## 📊 CSVログファイルの解説

受信機は解析結果をCSVファイルに保存します。Excel等で開いて分析できます。

### カラム（列）の意味

| 列名 | 内容 | 詳しい解説 |
| :--- | :--- | :--- |
| **Timestamp** | 受信時刻 | データを受信した瞬間の時間。 |
| **Status** | **判定結果** | `OK` なら正常。`DATA_CORRUPT` はデータ化けあり。 |
| **RecvCounter** | 受信番号 | パケットの通し番号 (0, 1, 2...)。 |
| **ExpectedCounter** | 期待番号 | 本来来るはずだった番号。ここが飛んでいると「パケットロス」です。 |
| **BitErrors** | **誤りビット数** | データの化け数。**0なら正常**。数値があればその分だけ壊れています。 |
| **RxHex** | **受信データ** | 実際に受信した生データ (Hex)。 |
| **TxHex** | **正解データ** | **「本来送られたはずの正しいデータ」**。RxHexと比較して、どこが化けたか確認できます。 |

## 🚀 使い方 (Quick Start)

### 1. 送信機 (Sender) を動かす

コマンドプロンプトで以下を実行します。3秒待つなどの工夫は不要です。

```bash
# 基本 (COM10から送信)
python kiss_sender.py --port COM10 --pn9-reset-each

# 詳細設定 (サイズ16, 間隔0.5秒)
python kiss_sender.py --port COM10 --baud 9600 --size 16 --interval 0.5 --pn9-reset-each

```

※ `--pn9-reset-each` を付けると、GUI側の `[x] PN9-RST` に対応します（推奨）。

### 2. 受信機 (Receiver) を動かす

**GUI版（ANT_Analyzer_GUI.py）の使用手順:**

1. **起動**: `python ANT_Analyzer_GUI.py` (またはEXE) を実行。
2. **ポート選択**: `[SCAN]` を押し、**TX LINK**(送信側) と **RX LINK**(受信側) を選択。
3. **ログ設定**: `[SELECT]` ボタンで保存先ファイル名を決定。
4. **設定合わせ**: `BAUD`, `SIZE` を送信側と一致させる。
* **推奨**: `[x] PN9-RST` にチェックを入れる（送信側もリセットモードにする）。


5. **開始**: `[INITIALIZE DATA LINK]` をクリック。
* **Auto Sync機能**により、いつボタンを押しても自動でタイミングを合わせます。

## ⚠️ トラブルシューティング

* **Q. Statusが全部 `DATA_CORRUPT` になる**
* A. 送信側と受信側で `PN9-RST` (リセットモード) の設定が逆になっていませんか？ 両方ともON（またはOFF）に揃えてください。
* A. `SIZE` (パケットサイズ) は合っていますか？


* **Q. 途中から受信したらエラーが出た**
* A. 最新のGUI版 (v8.0以降) を使ってください。自動同期機能が解決します。


* **Q. 文字化けして読めない**
* A. `BAUD` (ボーレート) が無線機の設定と一致しているか確認してください。
